# Santa Catarina Open Data (dados-sc-gov-br)

Santa Catarina Open Data is a state government open-data portal for Brazil running **CKAN** (~112 datasets).

**URL:** [https://raw.githubusercontent.com/api-evangelist/dados-sc-gov-br/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/dados-sc-gov-br/refs/heads/main/apis.yml)

## API
- Base: `https://dados.sc.gov.br/api/3/action` · [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://dados.sc.gov.br)
